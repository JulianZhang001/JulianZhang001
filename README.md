# 居老师讲AI

**西南大学博士后｜AI 工具开发者｜把工作流做成能交付的产品**

> 一位教师，用 AI 重写自己的办公方式。
> 领域专长 × AI 工具 = 差异化竞争力。

## 我是谁

我是张军，网名「居老师」—— **「居老师讲AI」** 自媒体主理人，坐标重庆。

西南大学博士后。我不写「AI 将改变世界」这类文章，
我只做一件事：**把自己每天真在用的工作流，沉淀成别人拿走就能用的工具。**

## 我在做什么

| 方向 | 一句话 |
| --- | --- |
| **公文自动化** | 依据国家标准 GB/T 9704，把公文 Word 排版交给脚本，30 秒出规范件 |
| **Skill 沉淀** | 把我写公文、管项目文件的判断力，封装成 AI Skill，别人装上就有 |
| **AI 工具开发** | 抽奖工具、座位牌批量生成、桌面提醒板——都是解决真实麻烦的小工具 |
| **知识管理** | 项目文件管家 Skill，让 AI 参与文件整理而不是只会写代码 |
| **自媒体** | 「居老师讲 AI」，把 AI 实践讲给同行听 |
