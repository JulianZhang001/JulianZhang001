做一件事做到能用：把**公文写作与排版**这条链路全自动化。

| 项目 | 解决什么 |
| --- | --- |
| [一键公文写作 Skill](https://github.com/JulianZhang001/gongwen-writing-skill) | 正式公文、公务材料、新闻稿的润色与结构化写作，装上即用 |
